# Блок Сити — записи для продолжения работы

Сюда записываются все изменения и решения, чтобы в новом чате было видно, что сделано и что нет.

## Решения (13.11.2026)
- Игра по концепции Тима «Block Puzzle — City Builder». Рабочее название **«Блок Сити»** (Тим: «пока разницы нет», можно сменить).
- **Godot 4.7.2**, 2D, рендер `gl_compatibility` везде (2D, лёгкий, работает на любых телефонах).
  Сборка на GitHub Actions как у `timnuri/durak` и `timnuri/shooter3d`: APK в Releases (тег `latest`), браузерная версия на GitHub Pages.
- Поле **8×8** (в концепции 10×10; Тиму без разницы; размер задаётся раскладкой уровня, легко поменять).
- Блоки рисуются кодом в 2D «объёмно» (тень, блик) — `UI.draw_block`. Картинок нет, звуки тоже создаются кодом (`sfx.gd`).
- Порядок версий: **0.1** бесконечный режим + кампания 20 уровней → **0.2** доводка по отзыву Тима → **0.3** город → **0.4** реклама, статистика, публикация.
- **Город (решение Тима, 13.11):** механика как предложил Claude — сетка города, фигуры-участки (дорога, провод, труба, кабель, дома), дом работает, когда подключён ко всем 4 сетям (электричество, вода, дороги, интернет) к своим станциям (электростанция, насосная, депо, серверный центр). Заполненная линия в городе **не исчезает**, а становится «магистралью».
- **Что даёт город:** Тим не знает, на что тратить VIP-валюту, а усилители нужны на сложных уровнях → город в первую очередь **производит усилители** (вариант B). Монеты (обычная валюта) — за уровни и бесконечный режим.
- **20 уровней**, новые механики по одной, без перегруза (просьба Тима): 1–5 основы, 6–8 лимит ходов, 9–11 камни, 12–14 ямы, 15–17 лёд, 18 ящики, 19 многоэтажные ящики («этажи»), 20 финал (всё вместе).
  «Этажи» пока сделаны как **многоэтажные ящики** (у ящика 2–3 этажа, каждая линия снимает один). Настоящее многослойное поле — позже, если Тим захочет.
- Медали за количество ходов. Пороги подобраны ботом (`tests/balance.gd`): золото ≈ лучшие 25% побед бота +1 ход, серебро ≈ 60% +3.
- Раздача фигур честная: в уровнях всегда даётся набор из 3 фигур, который можно поставить целиком (`Shapes.deal`, mercy=1). В бесконечном режиме с ростом очков это «милосердие» падает до 40%, чтобы партия когда-то кончалась.
- Подпись APK: `android/release.keystore`, пароль в workflow (`blockcity2026`) — **только для тестов**. Перед Google Play сделать отдельный ключ загрузки и хранить в Secrets репозитория.

## Сделано (версия 0.1, 13.11.2026)
- `scripts/board.gd` — логика поля: установка, очистка рядов и столбцов, камни (линия очищается, камень остаётся), ямы (дыры, линия короче), лёд (разбивается, когда очищается линия через клетку), ящики с этажами, очки и комбо (комбо держится, если очищать линии хотя бы раз в 3 хода), сохранение в словарь.
- `scripts/shapes.gd` — 37 фигур с весами, раздача 3 фигур с проверкой, что их можно поставить.
- `scripts/levels.gd` — 20 уровней, цели (очки / линии / лёд / ящики, можно несколько сразу), лимит ходов, медали, подсказки при первом запуске уровня с новой механикой.
- `scripts/bot.gd` — жадный бот (для проверки уровней и для подсказки на 1-м уровне).
- `scripts/game_view.gd` — рисование поля и лотка, перетаскивание пальцем (фигура над пальцем, «призрак» на поле, подсветка линий, которые очистятся, лёгкий «магнит»), анимации: появление фигур, «пружинка» при установке, исчезновение клеток волной, вспышки линий, частицы, тряска при больших комбо, надписи «+очки», «Отлично!», «Комбо ×N». Фигуры, которые никуда не влезают, становятся бледными.
- `scripts/game_screen.gd` — партия: бесконечный режим (сохраняется после каждого хода, можно продолжить), уровни (цели, ходы, медали, награды), усилитель **«Заменить фигуру»** (выбрать фигуру → она меняется на случайную), окно «Некуда ставить!» с предложением замены, покупка замены за монеты, выход с подтверждением.
- `scripts/main.gd` — меню (логотип-город из блоков, падающие блоки на фоне), экран уровней (медали, метки новых механик), магазин (1 замена — 40 монет, 5 — 180), настройки (звук, вибрация), кнопка «Назад» Android. «Город» — окно «скоро, версия 0.3».
- `scripts/save.gd` — сохранение: рекорд, монеты, замены, медали, статистика, настройки, незаконченная партия.
  Награды: бронза 10, серебро 25, золото 50 монет **всего** (при улучшении медали доплачивается разница), за первое золото +1 замена. Бесконечный режим: 1 монета за 250 очков. На старте 3 замены.
- `scripts/sfx.gd` — звуки кодом (взять, поставить, очистка с ростом тона по комбо, победа, поражение, монеты) и вибрация.
- Иконка `game/icon.png` (город из блоков), сделана скриптом PIL.
- Тесты: `tests/test_logic.gd` (логика, запускается в сборке), `tests/balance.gd` (бот по всем уровням), `tests/shots.gd` (снимки экранов).

## Как проверять в чате Claude
- Godot: `git clone https://github.com/timnuri/durak` → `git fetch origin get-godot && git checkout origin/get-godot -- godot.zip` (прямое скачивание с GitHub releases отсюда отвечает 504).
- Логика: `godot --headless --path game -s res://tests/test_logic.gd`
- Баланс: `godot --headless --path game -s res://tests/balance.gd -- 60` (≈2–3 мин), печатает проценты побед и готовые пороги медалей.
- Снимки: `xvfb-run -a godot --rendering-driver opengl3 --path game -s res://tests/shots.gd --resolution 390x844 -- /tmp/shots`
- В скриптах для `-s` нельзя писать типы `GameScreen`/`Save` напрямую (автозагрузки ещё не видны при компиляции) — брать через `root.get_node("Save")` и без типов.

## Идеи усилителей для города (предложение Claude, Тим ещё не решил)
- Электричество → «Разряд»: очистить выбранный ряд.
- Вода → «Волна»: очистить выбранный столбец / растопить весь лёд в линии.
- Дороги → «Бульдозер»: убрать 1 клетку (и камень тоже).
- Интернет → «Перезагрузка»: заменить все 3 фигуры.
- Комбинации: Электричество + Интернет → «Разряд+» (ряд и столбец крестом); Вода + Дороги → «Ливень» (3 случайные линии) и т. д.
- VIP-валюта (если понадобится): оформление поля и блоков, темы города, ускорение строительства, «продолжить партию» в бесконечном режиме.
