# Блок Сити (Block Puzzle — City Builder)

Мобильная головоломка на Godot 4.7: классический Block Puzzle, кампания из уровней с медалями
и (в версии 0.3) свой город, который строится той же блочной механикой.

- Браузерная версия (для быстрой проверки): https://timnuri.github.io/blockcity/
- Приложение Android: раздел **Releases → latest → blockcity.apk**

Сборка делается сама на GitHub при каждом изменении (`.github/workflows/build.yml`).
Все решения и ход работы — в `HANDOFF.md`.
